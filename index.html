How it works

I built this because job boards show everything and nothing tells you which roles you qualify for, or when a program opens.

Decisions I made

  • Catch APMs by shape, not name. Programs hide behind titles like "Product Manager-in-Training" or "Product Analyst", so a pattern tagger flags APM-shaped titles. In this snapshot it caught 99 roles that never say "APM".
  • Filter out, then flag. Senior, Master's-only and PhD roles are removed. Anything that doesn't state a start date gets a "verify" tag instead of being dropped, so nothing good slips through silently.
  • Alert only on product roles. Data roles update quietly, so the alarm stays meaningful.
  • Directory plus live cards. The directory is strategy, the cards are action. Big programs open once a year; postings come and go daily.

Live version vs. this demo

  • Live: a Python script polls public feeds every 15 minutes, rewrites the dashboard, and flies a desktop alert across my screen when a new eligible product role appears.
  • Demo: the same dashboard frozen at one sweep, with sample pipeline data in place of my real applications.
  • Sources: the open-source SimplifyJobs new grad and Summer 2027 internship lists, plus a hand-curated program watchlist.
